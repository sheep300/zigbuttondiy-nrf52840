# Historique

La version courante est V7 à la racine. Les versions d’archive sont des étapes de diagnostic, pas des versions recommandées pour un nouveau flash.

- original_cr2032 : copie des sources de travail antérieures et des anciens UF2 ; les sources ne sont pas garanties correspondre à chacun de ces binaires.
- diagnostics/C : GPIO/LED sans Zigbee ni ADC.
- diagnostics/D et D2/D3/D4 : diagnostics Zigbee et sommeil.
- D5 : correction de la configuration sleepy après initialisation.
- diagnostics/LIPO : candidat de mesure LiPo antérieur à la correction D5.
- V6 : sommeil corrigé, file de toggles et suivi d’envoi, mesure LiPo.

Les SDK, bibliothèques tierces, répertoires de compilation et journaux domotiques ne sont pas inclus.
